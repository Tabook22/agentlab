# Illustrated history after a mission finishes

Open a completed mission's **Answer**, then choose **Show history steps**.
The same button is available on completed missions opened from **Mission history**.

The viewer tells the story through seven chapters: understanding, dividing work,
human permission, worker processing, exchanges, revision and final delivery.
Chapter counts come from saved events. A chapter without evidence says **Not
recorded**, rather than inventing a question, a permission or an approval.

Use **Play the story**, Previous, Next or the step slider to reconstruct the run.
The colored directional arrow shows the selected step's actual sender and
receiver. Faint paths show previous exchanges. Every worker remains on the
drawing; workers not yet created are explicitly marked. Select an agent to
inspect its input, public processing and output at that point in time. The
ordered step list includes return feedback and repeated attempts.

**Whole story** returns to the delivered result. The final answer can also be
opened inside the viewer. Older recordings without a master approval event are
explicitly labeled. Playback changes no mission data and makes no AI requests.

**Save illustration** downloads a local SVG image containing the communication
map, chapter counts and the chronological step summaries. It uses the existing
event data without sending it to an image service. SVG text is escaped.

The viewer supports English and Arabic labels, keyboard-accessible controls, a
native modal dialog with Escape to close, narrow-screen scrolling and reduced
motion. It shows public plans and artifacts, not private model reasoning.
