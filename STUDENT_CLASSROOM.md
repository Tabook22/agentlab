# Student classroom

The **Team** view now opens in **Student classroom**. It organizes the diagram as
**Your goal → The team works together → The answer**, with the master and all
recorded or planned workers visible. A worker not yet created is marked as a
planned role. Each agent shows input, processing and output checkpoints.

**Follow active agent** keeps the relevant agent's work in the focus panel as
records arrive. Selecting an agent turns off automatic focus; turn it back on to
follow activity again. A pending model/tool request is labeled as waiting for a
response, rather than being presented as completed work.

Exchanges use labeled information cards: Task, Evidence, Idea, Question, Draft,
Feedback, Approval and Result. Icons and labels accompany the colors. The most
recent message has a readable preview and a **What is inside this card?** drawer
for exact recorded data. The card strip shows the latest twelve exchanges at the
selected point. Earlier exchanges remain accessible through replay and history.

**Play the story** and the Previous/Next controls walk through recorded
educational steps. Choosing a message card visits its send event and opens its
payload. This pauses the local view, not the backend. **Return to latest** rejoins
the newest activity. Playback makes no model calls. Parent mission-status banners
and duplicate playback controls are hidden in Student Mode so they cannot
misrepresent an earlier local replay step. Critical pause, clarification,
approval, cancellation and failure alerts remain visible with recovery controls.

The colored arrow identifies a recorded exchange. A readable card travels along
its route once when motion is enabled during playback or live following. It does
not imply another delivery. Faint dashed lines show team coordination, not extra
messages. Motion can be disabled and respects reduced-motion preferences.

Larger text, plain explanations and a three-card input/processing/output panel
keep technical evidence in expandable drawers. **Explore details** opens the
existing workbenches, including question-answer and recovery controls. Map and
blueprint views remain available. **Read the final answer** and **Show history
steps** appear when delivery is present in the visible record.

The interface supports English and Arabic. Narrow screens can scroll the map
horizontally; other sections stack vertically. Nothing in this feature changes
agent scheduling, grants permission, starts paid work, or displays private model
reasoning.
